2. **The Bybit API key must be granted `ContractTrade`.** Every order-mutating endpoint is currently refused; the engine reports this as `trade_permissions_ok: false` and the arm gate now blocks on it.
3. **Live-profit optimisation requires live evidence.** Per `AI_EXECUTION_RULES.md` rule 9, autonomous optimisation must be justified with live production evidence; the dry-run suite validates control flow only and is not used as profitability evidence.
