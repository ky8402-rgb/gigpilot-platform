OwnerAuth.login() compares it against the configured owner and refuses on mismatch ("Access denied: personal single-owner account"), recording a throttle failure each time. A form that omitted this field could therefore never succeed and would push the operator toward a lockout while looking correct. #}
{# Two ways in, both on POST /api/auth/login: the rolling authenticator code, or the break-glass PIN. The PIN is an ALTERNATIVE credential on the same endpoint, not a separate page, so it is a mode switch here rather than a link. #}

Lost the authenticator device? Switch to the break-glass PIN. Repeated failures are throttled server-side; a service restart clears the lockout, and only an operator can do that.

The session is carried in an HttpOnly cookie, so no script on this page can read it. This console never stores a credential in localStorage, sessionStorage, or IndexedDB.
