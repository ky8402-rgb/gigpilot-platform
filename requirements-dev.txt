# live exchange credentials does not carry a test framework.
#
# Installed by scripts/deploy-ec2.sh, which runs the Python safety gates on the deploy host before
# the service is restarted (fail-closed: a red gate aborts the rollout).
pytest>=8.0.0
pytest-asyncio>=0.23.0

# Required by `starlette.testclient`, which `fastapi.testclient` re-exports. Every gate that uses
# TestClient (test_dashboard_delivery, test_health_disclosure, test_auth_throttle,
# test_control_plane_auth) fails to even IMPORT without it.
#
# This was previously satisfied BY ACCIDENT: httpx arrived as a transitive dependency of
# `google-genai`, itself unused. Removing that unused package exposed the phantom dependency and
# broke CI — so it is declared here explicitly, where it belongs, instead of relying on chance.
httpx>=0.27.0

# --- Static analysis. CI and the deploy host run `ruff check .`, `flake8 .` and `mypy .` before the
# release is allowed to proceed, so all three must be declared here or the gate cannot execute.
#
# flake8 is deliberately NOT redundant with ruff: it enforces the syntax/undefined-name rules (E9,
# F63, F7, F82) that this project pins in `.flake8` as its correctness gate, while ruff owns the
# broader style set. It was missing from this file after the Python-only refactor — the CI lint step
# would have failed with "No module named flake8", which is exactly the phantom-dependency class of
# bug the httpx note above exists to prevent.
mypy>=1.11.0
ruff>=0.6.0
flake8>=7.0.0
